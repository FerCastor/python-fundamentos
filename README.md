# Python — Fundamentos e Prática

Repositório dedicado ao estudo e à prática de conceitos fundamentais de Python, com foco no desenvolvimento da lógica de programação e no fortalecimento da base computacional.

Os exercícios estão organizados por temas, acompanhando a evolução dos conteúdos estudados.

## Organização

| Diretório | Conteúdo |
|---|---|
| `estrutura_sequencial/` | Entrada e saída de dados, variáveis e operações |
| `estrutura_de_decisao/` | Estruturas condicionais |
| `estrutura_de_repeticao/` | Laços de repetição |
| `funcoes/` | Definição e utilização de funções |
| `listas/` | Manipulação de listas |

## Tecnologias e ferramentas

- Python
- uv — gerenciamento de dependências e ambiente de desenvolvimento
- Ruff — formatação e análise estática de código

## Objetivo

Consolidar conceitos essenciais da linguagem por meio da resolução de exercícios práticos, priorizando a compreensão da lógica, a legibilidade e a qualidade do código.
